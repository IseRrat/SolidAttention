## 必须在阶段 0/1 解决的开放项

1. **模型与上游接口**：锁定一个可公开获取且支持 128k 上下文的模型、权重哈希、量化格式、llama.cpp 提交、CUDA 工具链及适配点。记录是否需要上游改动或独立 backend 模块。
2. **代表 token 与打分**：InfLLM 允许多个代表 token，而 SolidAttention 本文未列出所选数量；确定本项目的数量、分数聚合和 query head 到 KV head 的映射，并做召回/准确率扫描。
3. **位置语义**：确认选块后 RoPE、causal mask、绝对 token 位置如何传入 attention；不得因物理槽位重排改变语义。
4. **预算取整**：初始/局部/动态三类预算按 token 还是整块保留时的取整和交叠处理，用测试固定边界行为。
5. **I/O 策略**：确定文件布局、块头、数据对齐、direct I/O、队列深度、每层写缓冲与 SSD 容量；先以正确性为准，再扫描性能。

以上开放项有些论文没有给出可直接编码的完整细节。实施时应记录采用的工程补全，不把它们写成论文原始设定。
